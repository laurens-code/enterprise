📘 README.md — D’s Cutz Barbershop Website
💈 D’s Cutz — Modern Classic Barbershop Website
A fully responsive, modern‑classic barbershop website built with React, featuring a clean layout, hero section, services, pricing, gallery, and contact information. Designed for fast performance, mobile‑friendly browsing, and easy customization.
---
🚀 Features
• Responsive design (mobile‑first with full desktop layout)
• Hero section with custom barbershop imagery
• Services grid showcasing core offerings
• Pricing section with clear service costs
• Gallery for showcasing cuts and shop visuals
• Sticky navigation bar with booking CTA
• Clean, modern color palette (black, white, red accents)
• Component‑based architecture for easy scaling
---
🛠️ Tech Stack
• React (Vite) — fast development & optimized builds
• CSS — custom styling with responsive media queries
• JavaScript (ES6+)
• Modern layout techniques (Flexbox + CSS Grid)
---

📦 Installation & Setup
1. Clone the repository
git clone https://github.com/your-username/dscutz.git
cd dscutz
2. Install dependencies
npm install
3. Start development server
npm run dev
4. Build for production
npm run build

📱 Mobile Responsiveness
The site includes a full responsive layout using:
@media (max-width: 768px) { ... }

This ensures:
• Navigation stacks vertically
• Buttons become full‑width
• Grids collapse into single‑column
• Hero text scales properly
• Footer reorganizes for readability
